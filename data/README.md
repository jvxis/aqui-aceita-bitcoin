# Dados

`municipios_ibge.csv`: os municípios do Brasil com o código do IBGE, a UF e a coordenada da sede. Vem do
projeto [kelvins/municipios-brasileiros](https://github.com/kelvins/municipios-brasileiros) (licença MIT,
© 2016 Kelvin S. do Prado), gerado em 04/11/2026 a partir de `csv/municipios.csv` e `csv/estados.csv`, só
com as colunas que o `btcmap_sync.py` usa para saber em que município fica cada comércio.
